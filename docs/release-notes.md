本次更新（相比上一版 1.117.0）：

- 时间块支持拖拽边缘调整时长：桌面端鼠标移到块的左右边缘即可拖动（光标变左右箭头），
  移动端先点选时间块、两端出现把手后再拖。拖拽期间只做预览，松手才提交，一次手势一条撤销记录；
  Google 日历同步来的块不提供该操作。
- 事件名新增「两行 / 单行」显示方式，可在「我的 → 设置 → 操作与布局 → 事件名显示」切换
  （带真实格子预览）。名字被省略号截断时，手机长按、桌面悬停即可看全名。
- 时间网格标签改为两行显示，长事件名不再被单行截断；网格气泡补上时间段与分类名。
- 修复事件栏中长事件名折行把条目撑高的问题。
- 修复极端字体放大时网格块内容溢出到相邻块的问题。
- 对齐 Flutter 3.44 / Dart 3.13 的依赖解析结果。
