本次更新（相比上一版 1.116.0）：

- 修复一个会覆盖「分类与子事件」的同步问题：新安装的 App 不再自动生成「学习 / 工作 / 运动」等默认分类，
  本地没有自己的分类时只会从远端拉取，绝不会把远端覆盖成空。
- 修复历史版本自动生成的默认分类再次覆盖远端的问题：这些默认分类会被识别为非用户数据并从同步中剔除，
  因此被污染过的设备打开后会自动从远端恢复正确的分类与子事件。
- 「临时」分类改为只保存在本机，不再参与同步，避免它被推到远端或顶掉远端同名分类。
- 修复 iOS 版「我的 → 关于应用」的「检查更新」入口（iOS 无应用内自更新通道，现已隐藏）。
- 修复 iOS 上桌面小组件相关的报错（该功能仅 Android 支持，iOS 现已跳过）。
