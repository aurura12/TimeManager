本次更新：

- 新增「更多功能」：隐藏底部标签后，可从「我的」左上角设置菜单旁的九宫格图标直接打开对应页面；返回后标签仍保持隐藏，页面状态也会保留。
- 优化隐藏页面的返回体验：日记与出行在加载期间也可返回；窄屏下的记录页会将部分工具收进菜单，避免顶部拥挤。
- 新增「背景图片」：在「我的」设置里选一张本机照片作为全窗口背景，照片与界面的透明度都能单独调，设置只存本机、不参与同步。
- 更新提示里现在会显示安装包大小。
- 优化「查看对方日程」：打开和切换日期时先用本机缓存立即显示，再在后台刷新最新内容，不再有空白等待。
- 日程保存更流畅：合并连续的保存请求，历史数据的整理改到后台处理。
- 统计页和词云加载更快。
- 修复桌面端日期导航的对齐问题，日期与星期/网格对齐更整齐。
