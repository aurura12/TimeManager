本次更新（相比上一版 1.121.0）：

- 记录、删除、打卡这些手上有动作的地方补上了触感反馈：
  - 刷子每刷进一格轻震一下，同一格里来回移动不会连续震；
  - 拖动时间块边界时每跨一格跟手震一次，松手提交成功再给一次确认；
  - 双击删除时间块、删除分类或目标时震一次（删空格位、只读视图不震）；
  - 打卡成功给一次稍重的震动，失败不震；
  - 日记左右滑动切日沿用原来的轻震，现在和上面这些统一受同一个开关控制。
- 「我的 → 操作与布局」新增「触感反馈」开关，默认开启。关掉后以上所有震动全部停止，
  设置保存在本机、换身份不受影响；桌面端没有震动硬件，开关不会产生额外影响。

此前版本（1.119.0）的更新内容：

- 同步入口统一收进「我的 → 同步中心」：记录、日记、出行、打卡四个页面不再各自放同步按钮，
  只有同步异常（待同步 / 离线 / 失败 / 冲突）时才在顶栏出现状态灯，点它直接进入同步中心处理。
  一切正常时顶栏不会多出任何图标。
- 同步中心新增「拉取远端」：出行和打卡可以主动把远端改动取回本地。出行拉取会覆盖本地还没
  上传的日期，操作前必须先确认；打卡拉取是按 ID 合并，不会丢本地记录。
- 日记改成自动上传：停止输入 3 秒、切换日期、切到后台、离开日记页、冷启动和回到前台，都会
  自动把还没上传的日记推上去，不用再手动同步。
- 日记冲突可以自己处理了：远端被其他设备改过时，编辑框上方会出现「处理冲突」。点进去能逐块
  对比本地与远端，每一块单独选「用本地 / 用远端 / 两边都留」，也可以整体采用某一边，或合并后
  再编辑上传。查看冲突期间远端又变化时会拒绝覆盖，不会悄悄吞掉别人刚写的内容。
  同步中心的日记卡片也会显示「去处理冲突」，点了直接跳到冲突那一天。
- 日记的自动拉取和自动保存行为保持不变：进页面、切日期仍会自动拉最新内容，本地有未上传的修改
  时不会被远端覆盖。
