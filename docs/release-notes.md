本次更新（相比上一版 1.118.0）：

- 记录页新增「当前时刻」小圆点：只在今天这一列标出现在的位置，每分钟自动下移；首次打开、
  从别的日期切回今天、跨日推进后会自动滚到现在附近，切到别的标签再回来不会打乱原来的滚动位置。
  不需要的话可以在「我的 → 设置 → 操作与布局 → 当前时刻标记」关掉。
- 日记页支持左右滑动切换日期：在编辑框以外的区域左滑看后一天、右滑看前一天，带轻触感反馈；
  编辑框内仍然只做文字选择，桌面用鼠标横向拖动不会误触。本地保存失败时不会切走。
- 桌面端（Windows / macOS）的纵向列表新增常显滚动条，长列表一眼能看出当前位置；
  移动端保持系统默认的无滚动条样式，时间网格列也不会多出竖条。
- 附带整理：网格行高与上下内边距统一走设计令牌，避免以后调整行高时「现在」小圆点、
  点击命中与初始滚动位置互相错位。
