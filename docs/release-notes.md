本次更新（相比上一版 1.114.0）：

- 新增桌面侧栏导航：宽屏下可在「我的 → 设置 → 外观设置 → 桌面布局」把底部标签栏换成左侧竖向导航，事件栏宽度也能拖拽调整，默认宽度与底部导航一致；窗口变窄时自动回到底部导航。
- 新增「键盘快捷键」设置：在「我的 → 设置 → 外观设置 → 键盘快捷键」查看和自定义按键，覆盖全局搜索、切标签、记录页与日记页切日、撤销/重做、新建、保存表单和关闭弹层，相关按钮悬停即可看到对应按键。
- 目标页起床卡片新增「查看更多」：可按最近 30 天 / 90 天 / 全部或自选日期区间查看平均、最早、最晚起床时间、趋势图与每日明细。
- 日记页切日期更方便：日期按钮两侧新增前一天 / 后一天按钮，不用再打开日历面板；桌面端悬停可看到对应快捷键。
- 桌面端出行改版：多月日历一屏排列，月份数量随窗口大小自适应，表格与日期详情重新排版，整体样式与移动端对齐。
- 修复桌面端右侧事件栏展开分组后无法上下滚动的问题。
- 修复出行月历中记录圆点与日期数字重合的问题。
- 修复开启背景图片后「更多功能」菜单底色不透明、下层内容穿透的问题。
